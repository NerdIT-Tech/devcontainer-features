# Release-please with Conventional Commits

MUST: Commit subjects follow Conventional Commits; `conventional-commits.yml` enforces it in CI.
MUST: Versions and `CHANGELOG.md` entries are generated by release-please, never hand-edited.
MUST NOT: Bump `version.txt` by hand outside a release-please PR.

## Why

Per-feature versions and changelogs are derived from commit history; manual bumps drift from it.

## Verify

    rg "bump|version" --glob '**/CHANGELOG.md' -i | rg -v "release-please|^\s*$" && echo "CHECK" || echo "OK"
